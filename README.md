# NES Sync — استعادة تاريخ مزامنة العرض

مشروع PHP ومتصفح لمزامنة عرض المحاضر وشاشة التحكم والملاحظات عبر غرف مشتركة، مع حالات مستضافة وتكييف محلي لـWindows/XAMPP. يستند هذا العمل إلى16مرجع مصدر محفوظًا تمثل10أشجار حزم مباشرة. هذا المستودع قيد الاستعادة، وليس إصدارًا مستقرًا معتمدًا.

## حالة النشر

هذا Commit تهيئة توثيقية. لا يُعد استعادة للكود أو دليلًا على اكتمال النشر. ستُنشر ملفات المصدر الفعلية في حالات Git مستقلة بعد مراجعة كل قائمة نشر، مع إبقاء اللقطات غير المؤكدة على فروع منفصلة.

ثبتت علاقة تكييف موثقة من حزمة opening-story V6 المستضافة إلى Local XAMPP V7. توجد تعارضات بين بعض تواريخ رصد المصادر وادعاءات وثائقها؛ لا تُختلق تواريخ تطوير أو علاقات Git أصلية. تواريخ Commits هي أوقات الاستعادة الفعلية.

## الخصوصية

حزمتان تضمان بيانات جلسات ملتقطة. تظل أصولهما خاصة؛ لا تُرفع بيانات الجلسات أو الأرشيفات الخام أو قيم الرموز. كل نسخة مشتقة ستوثق الاستبعادات وبصمات ملفات المصدر المسموح بها.

## التشغيل والتحقق

نقاط PHP المقروءة تستخدم JSON واستقصاءً قصيرًا وحالة ملفات مقفلة؛ لم يظهر اعتماد قاعدة بيانات أو Node فيها. بعض المتغيرات تسمح لحامل رمز الغرفة بالتنقل وتحرير نص المحاضر دون رمز المتحكم؛ هذه سياسة تاريخية يجب فهمها قبل النشر التشغيلي. لا يُشغَّل PHP على GitHub Pages.

لم تُنفذ اختبارات تشغيل. PHP غير مثبت في بيئة الاستعادة الحالية. ستكون تعليمات التشغيل الخاصة بكل حالة مرتبطة بمصادرها ووثائقها، مع فصل الخطوات المستنتجة عن الاختبارات المنفذة.

راجع [مركز التدقيق](https://github.com/Osama-Development/nes-development-master-audit) لنتائج العمل والأعمال المتبقية. لا تُمنح هنا رخصة جديدة للتطبيق، وتُحفظ إشعارات تبعيات OFL/MIT عند نشر ملفاتها.
